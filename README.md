# ROWE Tech Support v4

A focused web app for navigating an external automatic-door technical documentation library.

## Purpose
- No repair history, service-call database, or customer records.
- Browse manufacturers.
- Drill down into manufacturer folders/model families.
- Filter PDF/manual names.
- Open the original PDF directly from the source library.
- One manual library in one place.

## Important
ROWE Tech Support is an independent reference/navigation tool. The documentation remains hosted by its original source and the app does not imply manufacturer affiliation or endorsement.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.
